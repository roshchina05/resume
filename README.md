## Учебные проекты

### Sleepy — анализ активности и удержания

В Excel проанализировала 52 325 визитов 2 000 пользователей приложения. Рассчитала DAU, WAU, MAU и дневное удержание. Между 13-м и 14-м днями, на границе бесплатного периода, удержание снизилось с 43% до 25%.

[Кейс с графиком и методикой расчёта (PDF)](./Sleepy_case_Arina_Roshchina.pdf)

### Система управления ремонтами оборудования НПЗ

Описала текущий процесс управления ремонтами и предложила, как он будет работать после внедрения системы. Сформулировала требования для шести рабочих мест, спроектировала базу в MySQL из 18 таблиц и сделала HTML/CSS-прототип интерфейса.

В учебном обосновании оценила потери в 13,5 млн ₽ в год и рассчитала окупаемость проекта за четыре месяца. Подготовила комплект тендерной документации для учебного сценария по 223-ФЗ.

[Требования, модель базы, прототип и расчёты](./razrabotka_kis/)

### Контейнер безопасности

Подготовила техническое задание и тестовую документацию для учебного приложения по шифрованию трафика. Написала модульные тесты на pytest и провела приёмочное тестирование.
